Static Fail Mechanism

GIDL: Gate Induced Drain Leakage

GIDL은 셀 트랜지스터가 OFF 상태일 때 gate-drain 인접 영역에서 강한 전계가 형성되고, 이 전계로 인해 band-to-band tunneling이 유도되어 원치 않는 누설 전류가 발생하는 현상입니다.

GIDL 누설 위치 및 전자 이동

버튼을 누르면 GIDL 누설 경로가 표시됩니다.

OFF 상태
* 실제 상용 DRAM 단면 구조를 그대로 재현한 것이 아니라, GIDL이 발생하는 위치와 누설 방향을 설명하기 위한 교육용 단순화 도식입니다.

GIDL 핵심 설명

1. OFF 상태

Wordline이 OFF이면 access transistor는 꺼져 있어야 하며, 셀 캐패시터에 저장된 전하는 유지되어야 합니다.

2. 전계 집중

하지만 gate와 drain이 가까운 overlap 영역에서는 국부적으로 강한 electric field가 형성될 수 있습니다.

3. 누설 발생

이 강한 전계는 band-to-band tunneling을 유도하고, 그 결과 OFF 상태에서도 leakage current가 발생하여 저장 전하가 감소할 수 있습니다.

발표할 때 핵심 문장

“GIDL은 트랜지스터가 OFF 상태임에도 gate-drain 인접영역의 강한 전계 때문에 누설이 발생하고, 결과적으로 저장 전하가 줄어들어 retention 특성을 악화시키는 현상입니다.”

발표 시 주의할 점

이 그림은 실제 상용 DRAM 구조를 100% 동일하게 그린 것이 아니라, GIDL의 핵심 메커니즘을 직관적으로 설명하기 위한 시각화 자료라고 설명하면 됩니다.

Static Fail Mechanism

GIJL: Gate Induced Junction Leakage

GIJL은 gate bias에 의해 junction 주변의 electric field가 증가하면서 source/drain junction에서 발생하는 누설 전류입니다. DRAM cell에서는 storage node와 연결된 drain junction을 통해 저장 전하가 기판 방향으로 빠져나가 retention 특성을 악화시킬 수 있습니다.

GIJL 누설 위치 및 전자 이동

버튼을 누르면 junction leakage 경로가 표시됩니다.

OFF 상태
* GIJL 그림은 실제 상용 DRAM 단면을 그대로 재현한 것이 아니라, gate bias가 junction depletion region에 미치는 영향과 junction leakage 경로를 설명하기 위한 단순화 도식입니다.

GIJL 핵심 설명

1. Junction 형성

DRAM cell transistor의 source/drain diffusion은 P-type substrate와 PN junction을 형성합니다. 이 junction 주변에는 공핍영역이 존재합니다.

2. Gate 영향

Gate bias가 junction 주변의 전계와 공핍영역에 영향을 주면, junction leakage가 증가할 수 있습니다.

3. 저장 전하 감소

Storage node와 연결된 drain junction에서 누설이 커지면, 셀 캐패시터에 저장된 전하가 줄어들어 retention fail 가능성이 증가합니다.

발표할 때 핵심 문장

“GIJL은 gate bias가 junction depletion region에 영향을 주면서 source/drain junction의 leakage를 증가시키고, DRAM에서는 storage node 전하 손실을 통해 retention 특성을 악화시킬 수 있습니다.”

GIDL과의 차이

GIDL은 gate-drain overlap 부근의 강한 전계와 tunneling을 강조하고, GIJL은 drain junction depletion region을 통한 junction leakage를 강조하면 됩니다.

Dynamic Retention Fail Mechanism

PGE: Pass Gate Effect

PGE는 인접한 wordline 또는 passing wordline의 전계 영향으로 선택되지 않은 cell transistor의 barrier가 낮아지고, 저장 전하가 원치 않는 방향으로 빠져나가 retention 특성을 악화시킬 수 있는 현상입니다.

PGE 간섭 위치 및 누설 방향

버튼을 누르면 passing wordline에 의한 barrier lowering이 표시됩니다.

대기 상태
* PGE 그림은 실제 상용 DRAM 구조를 그대로 재현한 것이 아니라, 인접 passing wordline이 victim cell의 barrier를 낮추고 누설 가능성을 증가시키는 과정을 설명하기 위한 단순화 도식입니다.

PGE 핵심 설명

1. Victim cell은 OFF 상태

Victim cell의 wordline은 OFF 상태이므로 원래는 access transistor가 저장 전하를 잘 막아야 합니다.

2. Passing wordline의 간섭

인접한 passing wordline이 활성화되면 주변 electric field가 변하고, victim cell의 channel barrier가 낮아질 수 있습니다.

3. Barrier lowering에 의한 누설

Barrier가 낮아지면 storage node에 있던 전하가 더 쉽게 빠져나갈 수 있고, 이로 인해 retention fail 가능성이 증가할 수 있습니다.

발표할 때 핵심 문장

“PGE는 인접 passing wordline의 전계가 victim cell의 barrier를 낮춰 원래 OFF 상태에서 막혀 있어야 할 저장 전하가 더 쉽게 빠져나가게 만드는 adjacent wordline interference 현상입니다.”

GIDL/GIJL과의 차이

GIDL은 gate-drain overlap의 강한 전계, GIJL은 junction depletion region, PGE는 인접 wordline이 victim cell의 barrier를 낮추는 간섭 효과로 구분하면 됩니다.

Dynamic Disturb Fail Mechanism

1-RD: 1-Row Disturb

1-RD는 하나의 aggressor row가 반복적으로 activate/precharge되면서 인접한 victim row의 cell charge가 disturbance를 받고, 충분히 refresh되기 전에 저장 전하가 줄어들면 bit flip 또는 retention fail로 이어질 수 있는 현상입니다.

1-Row Disturb / RowHammer 시각화

버튼을 누르면 aggressor row의 반복 활성화와 victim row disturbance가 표시됩니다.

대기 상태
* 1-RD 그림은 실제 DRAM array layout을 그대로 재현한 것이 아니라, 하나의 aggressor row 반복 활성화가 인접 victim row의 저장 전하를 교란하는 RowHammer/1-Row Disturb 개념을 설명하기 위한 단순화 도식입니다.

1-RD 핵심 설명

1. Aggressor row 반복 활성화

특정 row가 짧은 시간 동안 반복적으로 activate/precharge되면 인접 row에 전기적 간섭을 줄 수 있습니다.

2. Victim row disturbance

직접 access되지 않은 victim row의 cell capacitor가 영향을 받아 저장 전하가 더 빠르게 줄어들 수 있습니다.

3. Bit flip / retention fail

Refresh 전에 저장 전하가 sensing margin 아래로 떨어지면 데이터가 반전되는 bit flip 또는 retention fail이 발생할 수 있습니다.

발표할 때 핵심 문장

“1-RD는 하나의 aggressor row가 반복적으로 활성화되면서 인접한 victim row의 저장 전하를 교란하고, refresh 전에 전하 margin이 무너지면 bit flip으로 이어질 수 있는 dynamic disturb mechanism입니다.”

RowHammer와의 관계

RowHammer는 이러한 row disturbance가 시스템 보안 취약점으로까지 이어질 수 있음을 보여준 대표 사례입니다. 여기서는 보안 공격이 아니라 DRAM reliability 관점의 1-row disturb 현상으로 설명합니다.

Write & Fail Timing Mechanism

tRDL: Write Timing Margin Fail

tRDL은 공간적으로 특정 누설 경로를 보여주는 fail이라기보다, write 동작 후 cell capacitor의 전압이 충분히 안정화되기 전에 다음 동작으로 넘어가면서 write margin이 부족해지는 timing fail로 설명할 수 있습니다.

tRDL Write Timing Margin 시각화

버튼을 누르면 정상 write window와 tRDL-short fail window가 비교 표시됩니다.

대기 상태
* tRDL 그림은 특정 물리적 단면 누설 경로가 아니라, write 동작 후 cell voltage가 목표 level까지 안정화되는 데 필요한 timing margin을 설명하기 위한 단순화 도식입니다.

tRDL 핵심 설명

1. Write는 시간이 필요함

WRITE command가 들어오면 bitline/write driver가 cell capacitor의 전압을 원하는 data level로 밀어줍니다. 하지만 cell voltage가 목표 level까지 안정화되는 데는 일정 시간이 필요합니다.

2. Timing margin 부족

tRDL 조건이 너무 짧거나 내부 delay margin이 부족하면, cell voltage가 충분히 안정화되기 전에 다음 동작이 진행될 수 있습니다.

3. Write fail 가능성

이때 cell에 저장된 전압이 sensing margin 근처에 머무르면, 이후 read 또는 refresh 과정에서 잘못된 data로 판단될 가능성이 증가합니다.

발표할 때 핵심 문장

“tRDL은 누설 위치를 보는 fail이라기보다, write 이후 cell voltage가 충분히 안정화되기 전에 다음 동작으로 넘어가면서 write margin이 부족해지는 timing-related fail로 볼 수 있습니다.”

시각화 포인트

GIDL/GIJL/1-RD처럼 전하가 빠져나가는 경로를 그리기보다, 정상 waveform과 tRDL-short waveform을 비교해서 ‘충분히 올라간 cell voltage’와 ‘margin이 부족한 cell voltage’를 보여주는 방식이 더 적합합니다.
